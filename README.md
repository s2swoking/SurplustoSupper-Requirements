# Surplus to Supper Requirements

This public repository contains business requirements for the Surplus to Supper operations platform. It intentionally contains documentation only; the application source code is maintained separately.

The requirements are presented in the [GitHub Wiki](https://github.com/s2swoking/SurplustoSupper-Requirements/wiki).

Anyone can read the public Wiki without signing in to GitHub. A GitHub account is required only to edit pages directly.
